# LiltView：命名与首版图标记录

- 日期：2026-11-06
- 状态：项目名 LiltView 已确认；本版配色已归档，当前图标采用 v0.2 彩色版本
- 正式项目名：**LiltView**
- 中文别名提案：**轻览**
- 建议命令名、图标名：`liltview`
- 简短介绍：**轻快看图，专注画面。**

## 命名意图

用 Lilt 与 View 组合，表达轻快、流畅的浏览体验。中文“轻览”强调轻量和直接；名称不绑定 Linux、某种图片格式或渲染技术，方便未来延伸到 Windows。

正式项目名已确定为 LiltView。名称确认不代表软件仓库名、包名、域名或商标已经预留。正式发布前应按实际发布渠道核对可用性。

## 图标概念

主体由三部分构成：开口的画框、两段山形、一点薄荷绿的光。画框与山形表达图片浏览，开口和光点让图形保持轻盈。图标不嵌入文字，避免小尺寸下出现难以识别的字母或字形。

采用深青底色、暖白线条与单一薄荷绿强调色，不使用复杂渐变、阴影或纹理。背景圆角方块外部透明。

| 颜色 | 色值 | 用途 |
| --- | --- | --- |
| 深青 | `#15343D` | 应用图标底色 |
| 暖白 | `#F4F7F1` | 画框与山形 |
| 薄荷绿 | `#7AE3BA` | 光点与品牌强调色 |

这些是品牌资产颜色，不强制作为图片浏览画布的颜色；实际看图画布仍应采用中性背景。

## 文件

以下为 v0.1 历史文件名。旧配色资产现归档于 `assets/icons/archive/v0.1/`；其中 `liltview-symbolic.svg` 仍在 `assets/icons/`，供新版本共用。当前应用图标见 `BRANDING-v0.2.md`。

| 文件 | 用途 |
| --- | --- |
| `liltview.svg` | 可编辑的主矢量图标，512 × 512 坐标系 |
| `liltview-small.svg` | 针对 16 / 24 / 32 像素优化的简化版本 |
| `liltview-symbolic.svg` | 使用 `currentColor` 的透明单色版本 |
| `png/liltview-{size}.png` | 16、24、32、48、64、128、256、512 像素 RGBA 导出 |
| `liltview.ico` | 包含 16、24、32、48、64、128、256 像素的 Windows 图标 |
| `preview.png` | 深浅背景和不同尺寸的检查图，不作为应用资源 |

图标使用项目内 SVG 直接绘制，PNG 与 ICO 从矢量源导出。16 / 24 / 32 像素版本使用专门的小尺寸源图，其他尺寸使用主图。

单色图标的 `currentColor` 需要由使用它的绘制路径提供；不同桌面图标加载器的着色行为应在集成时验证。

## 使用约定

- 保持图标正方形比例，不横向拉伸。
- 浅色和深色桌面均使用同一个带底色版本。
- 工具栏需要单色标记时使用 symbolic 版本，并按实际背景设置颜色。
- 正式展示名称使用 LiltView，放在图标旁边，不塞进图标内部；中文别名仍为提案。
- 设计文档和品牌说明统一使用正式项目名 LiltView。
