# 格式兼容支持待开发清单

2026-11-08 根据用户确认登记。本文列出的新增能力全部为 **待开发**，不代表已支持、已接入依赖或已通过兼容性／性能验收。当前已实现范围以 [IMAGE_FORMATS.md](IMAGE_FORMATS.md) 为准；本次仅更新规划。

## 文件格式

| 标识 | 格式 | 后续支持与验收范围 | 状态 |
| --- | --- | --- | --- |
| `avif` | AVIF | 静态有损／无损、透明、高位深；普通尺寸动画单独验收 | 待开发 |
| `jxl` | JPEG XL | 静态有损／无损、透明、高位深、渐进能力；动画单独验收；已有 JPEG 无损重压缩文件的读取 | 待开发 |
| `heif` | HEIF／HEIC | 明确容器和实际编码支持范围，先验收主图、方向、透明与高位深；集合／序列另列子项 | 待开发 |
| `apng` | APNG | 完整动画、透明、帧合成、帧时长和循环，不能以只显示首帧作为完成 | 待开发 |
| `webp-animation` | 动画 WebP | 在现有静态 WebP 之外新增完整播放、透明合成、时长和循环 | 待开发 |
| `icon` | ICO／CUR | 多尺寸条目选择、PNG／DIB 图像条目、透明／掩码；CUR 热点元数据，作为图片显示 | 待开发 |
| `qoi` | QOI | RGB／RGBA 无损读取；作为无损编解码性能对照 | 待开发 |
| `jpeg2000` | JPEG 2000 | 明确 JP2 容器及裸码流 J2K 的兼容子集，有损／无损、高位深和区域／分辨率能力分项验收 | 待开发 |
| `openexr` | OpenEXR | 半浮点／浮点、多通道文件的选层和 RGB(A) 显示；声明压缩、scanline／tile 和其他特性的支持子集 | 待开发 |
| `camera-raw` | 相机 RAW／DNG | 明确 DNG 与具体相机 RAW 子集；内嵌预览和完整显影分别验收，不能互相替代 | 待开发 |

相机 RAW 是一类带相机元数据的文件，不等同于下面的无文件头原始像素。列入相机 RAW 待开发项不代表一次性承诺全部厂商、机型及编码变体。高位深输入、HDR 到 SDR 映射、原生 HDR 输出是不同能力，按实际输出链路分别验收，不以转成 RGBA8 作为完整 HDR 支持。

## 原始像素输入与渲染

| 标识 | 类别 | 后续支持与验收范围 | 状态 |
| --- | --- | --- | --- |
| `raw-rgb` | 原始 RGB／灰度 | RGB24、BGR24、RGBA8、BGRA8、RGB565、Gray8／Gray16；高位深及浮点变体分项列明 | 待开发 |
| `raw-yuv` | 原始 YUV | 4:4:4、4:2:2、4:2:0，分别覆盖 planar、semi-planar、packed 布局；具体格式见 [原始像素方案](RAW_PIXEL_INPUT.md) | 待开发 |
| `raw-bayer` | 原始 Bayer／拜耳 | RGGB、BGGR、GRBG、GBRG；8／10／12／14／16 位、非打包及明确规则的打包数据；去马赛克和颜色处理 | 待开发 |

原始数据必须能够设置宽高、具体像素格式、位深、字节序、对齐／打包方式、文件偏移，以及各平面的偏移和行跨度。YUV 额外配置矩阵、范围、色度采样位置等；Bayer 额外配置 CFA 排列、黑白电平、白平衡和去马赛克等。参数、校验和显示流程见 [RAW_PIXEL_INPUT.md](RAW_PIXEL_INPUT.md)。

用户提到的 `UYUV` 暂按常见的 `UYVY` 记入计划；不创建名为 `UYUV` 的未定义格式，也不默认为另一种布局。后续如提供不同排列规则，再增加独立格式定义。

## 每项开发完成条件

- [ ] 确定解码／解析实现、依赖版本、许可证及发行包边界；原始像素项确定参数协议。
- [ ] 接入后台加载、能力查询、错误处理、取消、CPU／GPU 预算和适用的打开入口。
- [ ] 明确静态、动画、高位深、颜色管理、区域访问等实际支持子集，不以一个开关概括所有能力。
- [ ] 补齐合法、损坏／截断、异常尺寸、错误参数、预算边界和恢复行为的兼容样本。
- [ ] 补齐 [性能测试计划](../benchmarks/TEST_PLAN.md) 中对应输入、分段耗时及资源占用对比。
- [ ] 验收后才更新实际兼容表；没有实现的子能力继续保留为待开发。

本清单不引入新解码器、CLI 参数或 UI 设置，不修改公共 API、构建依赖及现有 62 个测试输入。所有新增格式的输入素材为 **待补充**，性能数据为 **未测量**。普通尺寸动画及超大静态图仍分别规划；不扩展到超大动图。CAD、PSD／PSB、AI、CDR、Sketch 等专用设计源文件仍不纳入。
