## 2. 最新需求：裁剪版 SDL 静态链接

- SDL3 的 CMake 配置固定为 `SDL_SHARED=OFF`、`SDL_STATIC=ON`。
- ImGui 后端显式链接 `SDL3::SDL3-static`，不通过可能选择动态库的通用别名。
- 保留既有子系统裁剪与 Wayland / X11 支持，不依赖发行版 SDL 的具体构建。
- 安装规则移除 SDL 动态库及其专用 RPATH；保留 SDL 原始许可证。
- 系统 OpenGL、Fontconfig、GIO / GLib、Wayland / X11 依旧按平台库使用；这里的“静态”只指 SDL，不表示整个程序完全静态。
- 旧构建 / staging 中已有 `.so` 不会自动删除，使用全新安装前缀验证本轮产物。

## 4. 回归入口

默认开发构建使用 Catch2 和 CLI / ABI 检查，不要求显示服务器：

```bash
cmake --preset dev -DLILTVIEW_WARNINGS_AS_ERRORS=ON
cmake --build --preset dev
ctest --preset dev
```

字体和文件资源回归加入后，标准开发配置为 **23 项**。具备本机 EGL / OpenGL offscreen 驱动、Python、gdbus 和 dbus-run-session 时，可显式开启另三项集成回归：

```bash
cmake --preset dev -DLILTVIEW_BUILD_DESKTOP_TESTS=ON
cmake --build --preset dev
ctest --preset dev
```

共 **26 项**，集成测试分别覆盖全菜单 / 默认属性查询、损坏字体后的完整启动、保存失败警告。每项使用临时目录和私有 D-Bus 会话，不写真实桌面配置。关闭全局菜单时也须关闭桌面集成测试，普通单元测试仍可运行。

设置单元测试在 Linux 子进程中用 `RLIMIT_FSIZE` 触发真实写入 / 刷新失败，确认原文件内容仍在、临时文件被清理；不改变父进程限制、不占满磁盘。它补充了 `/dev/full` 特殊文件拒绝路径，避免仅验证参数检查而漏掉真正的 I/O 失败。

静态链接核对：

```bash
readelf -d build/dev/app/liltview
nm -g --defined-only build/dev/app/liltview
```

检查动态依赖不含 SDL、主程序包含定义的 `SDL_Init` 符号。旧共享库文件可能仍在已有 build 目录，不以“目录是否存在 .so”作为链接方式依据。
