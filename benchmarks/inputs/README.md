# 棋盘格随机色块性能测试输入

2026-11-08 生成，62 个原创合成样本，图片合计 669,021,290 字节，约 638.03 MiB。按项目 Apache-2.0 许可证提供。没有下载外部素材，也没有修改应用代码或增加性能测试程序。

普通位图默认使用 **64×64 像素正方形随机色块**，相邻块交替使用深、浅色域，固定种子为 **20261108**。相同尺寸、相同内容组的不同格式使用同一份原始像素；有损压缩、调色板量化和 EXIF 方向样本另有标记。另提供 8px 密集棋盘和 128px 稀疏棋盘，便于比较块密度对压缩、解码和显示的影响。边缘不足一个方块的区域自然裁切。

| 目录 | 数量 | 尺寸与用途 |
| --- | ---: | --- |
| `static/normal/` | 40 | 普通位图 1920×1080、4000×3000、6000×4000、8000×6000，以及 SVG 复杂度分档 |
| `static/large/` | 14 | 10000×10000（100MP）、20000×20000（400MP）、40000×25000（1GP）、2000×50000（100MP 超长图） |
| `animation/gif/` | 8 | 640×480、1280×720、1920×1080；移动棋盘、色块更新、透明局部帧与循环行为 |

`static/normal/` 和 `static/large/` 内再按 `jpeg/`、`png/`、`webp/`、`bmp/`、`tiff/`、`svg/` 分目录；只创建实际含有样本的格式目录。

| 格式 | 总数 | 已生成变体 |
| --- | ---: | --- |
| JPEG | 12 | RGB baseline Q90、progressive Q90、EXIF orientation=6；4:2:0 色度抽样 |
| PNG | 14 | RGB8、RGBA8、原生 RGB16、Adam7、8 位索引色、8px / 128px 棋盘；压缩级别 6 |
| WebP | 6 | 有损 Q85、无损 RGB、无损 RGBA；仅普通尺寸静态图 |
| BMP | 7 | 不压缩 RGB24、RLE8、显式 alpha bitfields 的 BGRA32；含一张 100MP RGB24 |
| TIFF | 12 | Deflate strip、512×512 tile、RGBA、Classic TIFF、BigTIFF；均为单页，无金字塔 |
| SVG | 3 | 随机色块网格，方块边长 96 / 32 / 20px，分别 240 / 2040 / 5184 个 rect，超出画布部分裁切 |
| GIF | 8 | 30～120 帧；固定 10 / 25 / 50fps、可变帧时长、透明局部更新、disposal 2 / 3、无限循环与只播放一次 |

GIF 使用 256 色全局调色板。全帧样本移动棋盘并更新色块；局部帧样本先提供完整首帧，随后更新约 1/3 宽、1/3 高的矩形，其中以 32px 随机方块和透明块测试合成与 disposal。可变帧时长为 20、40、80、120、200ms 循环。只播放一次的样本不包含 NETSCAPE 循环扩展，其余样本的循环值为 0（无限）。GIF 不使用超大画布。

`manifest.json` 是逐样本清单，包含相对路径、源尺寸、MP、颜色模式、位深、内容分组、方块大小、编码选项、实际文件字节数和 SHA-256。GIF 还包含帧数、逐帧时长、单轮时长、循环和合成信息。`decoded_rgba8_bytes` 表示单个完整画布换成 RGBA8 的理论字节数，**不是**解码器工作集或进程内存实测值。JPEG EXIF=6 样本另记旋转后的显示尺寸。

`validation.json` 记录了全部 62 个文件的 SHA-256、尺寸、格式参数和完整解码核验。静态图通过 libvips 完整解码归约；GIF 通过 FFmpeg 完整解码，并独立解析帧时长、局部矩形、透明标记、disposal 和循环扩展。PNG 另检查各 chunk CRC，BMP 检查位数和压缩方式，TIFF 检查容器与 tile 参数。4000×3000 同组 PNG、BMP、无损 WebP、strip TIFF、tile TIFF、BigTIFF 的完整 RGB 解码流 SHA-256 相同。

全部样本的 `application_status` 都是 `not_tested`：输入完整性核验没有测试当前 LiltView 的打开成功率、速度或资源消耗。普通图中的大 BMP 也可能触发旧版本文件大小限制；超大样本用于实际观察当前版本的支持程度，成功、拒绝和预算不足都应如实记录。

棋盘格具有较高可压缩性，源文件小不代表解码画布小。当前最大 PNG 只有数 MiB，但完整 1GP RGBA8 画布为 4,000,000,000 字节。本套素材适合确定性对比、块边界和上传／渲染检查，不代替真实照片的内容分布。生成与核验已读取图片，开展冷缓存测量前必须重新准备对应缓存状态。

图片和 `preview.jpg` 由本目录 `.gitignore` 排除，保留在本机；说明、清单与核验记录可纳入版本管理。`preview.jpg` 是 1920×1080 JPEG 样本的预览副本，不计入 62 个测试输入。
