# Quiet Presence · 按需浮现

图片优先于控件。默认画面不展示 Dock、占位条或唤出把手，保持完整、稳定的观察空间。精心控制几何关系与显隐节奏，让工具栏在需要时出现，用后退场。

雾白与石墨继续复用项目的语义色板。底板、细边框和蓝紫交互色保持克制，通过精确的分组留白与图标光学中心维持一致性，不引入玻璃、渐变或装饰性动效。

Dock 固定锚定画布底部居中，距底边 16 DIP；不计算图片留白，不根据图片尺寸、内容或缩放改变位置，不为 Dock 预留画布空间。全屏与窗口使用相同交互原则。

默认隐藏。鼠标在画布底部 32 DIP 感应区连续停留 200 ms 后开始 120 ms 淡入；提前离开则取消计时。鼠标在感应区或 Dock 内时保持显示，离开两者后立即开始 120 ms 淡出。重新进入可中断淡出，保持透明度连续。

感应区不含状态栏与信息面板。更多菜单展开、Dock 键盘焦点有效期间保持显示；图片拖拽期间不触发唤出，任何从图片开始的拖拽都不被 Dock 接管。隐藏 Dock 不接收按钮命中。

显隐仅影响覆盖层透明度，不改变图片视口、不重算 FIT。100% / 适应窗口共用动作按钮，图标与 tooltip 始终表示下一步动作。菜单动作、快捷键和禁用状态复用现有菜单模型。

## 成功加载后的交互前提

Dock 唤出与画布双击切换，仅在当前图像成功加载、可正常操作时生效。无图、请求已排队、解码 / 原图加载 / 恢复未完成及加载失败时，不触发；即使仍有上一张图片可见，也不视为当前图像加载成功。状态失效时取消未完成的悬停计时，不让过期交互作用于下一张图片。

## 新增：双击画布切换缩放模式

- 鼠标左键双击图片画布（包括图片及画布空白）时，在 100% 与适应窗口之间切换；不依赖 Dock 是否可见。
- 适应窗口模式下双击：切到原始大小 100%；100% 模式下双击：切到适应窗口。手动缩放状态下双击，先回到适应窗口。
- 依据视图模式而不是数值比例判断：适应窗口恰好等于 100% 时，也仍按适应模式处理。
- 与 Dock 切换按钮共用同一份状态与可用性；双击后同步更新 Dock 图标和 tooltip。原尺寸不可用时，不执行切到 100% 的动作，适应窗口仍保持可用。
- Dock、弹出菜单、信息面板、标题栏和状态栏等 UI 区域的双击不触发；模态弹窗、原生文件选择及正在进行的图片拖拽优先处理输入。
- 双击本身不强制显示 Dock。窗口和全屏使用同一规则。
