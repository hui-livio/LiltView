# 核心实现分区

当前只有 `api/config.c` 实现 ABI 版本查询、配置和请求初始化，其余公共 API 仍未实现。

后续按职责增加目录与显式源文件列表：

- `api/`：公共 C 入口、参数校验和对象生命周期。
- `engine/`：调度、取消、事件队列与背压。
- `io/`：本地数据源、文件身份和分批读取。
- `codecs/`：位图解码与 SVG 栅格化适配。
- `cache/`：CPU 缓存与可选磁盘缓存。
- `platform/`：文件、线程和时钟的平台适配。

核心不链接 ImGui、spdlog、Catch2 或网络库。新增 `.c` 文件由 C23 编译器编译。
